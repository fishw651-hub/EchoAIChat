# 海洋通透主界面美化设计

## 目标

在不改变现有功能、数据流、路由或交互入口的前提下，为 Flutter 客户端的五个主 Tab 建立一致的“海洋通透”视觉语言。范围包括首页、智能体、群聊、网络和账户页，以及承载它们的移动端底部导航与桌面端侧栏。

成功标准：浅色和深色模式均保持清晰可读；主导航、页面标题、卡片、列表与空状态呈现统一层次；手机与桌面布局保持响应式；不增加依赖。

## 视觉方向

- 保留现有 `oceanSeed` 浅蓝品牌色，使用低饱和蓝色容器色、细描边和克制的渐变作为强调。
- 页面背景保持干净，内容以半透明表面、柔和阴影和 16 至 20dp 圆角形成层次，而非使用重阴影或高对比大色块。
- 选中状态使用蓝色胶囊底色或渐变，未选中状态保持弱化的中性色，避免抢占内容注意力。
- 标题采用更明确的字重和间距；辅助文本降低对比度；主要操作使用 `FilledButton`，次要操作使用 tonal 或 outlined 样式。

## 主题与通用组件

`AppTheme` 扩展现有 Material 3 主题令牌，统一页面表面、卡片、分组容器、输入框、按钮、分隔线和导航的颜色与形状。新的主题配置必须依赖 `ColorScheme`，避免为浅色或深色模式硬编码文字颜色。

新增的轻量级展示组件只在确有重复结构时提取，用于承载主 Tab 的分组容器、空状态和列表卡片。组件只负责样式和布局，现有 provider、导航回调和数据加载逻辑保持在原页面中。

## 主导航

移动端保留五个 Tab 和 `IndexedStack`。底部栏使用带上边描边的表面容器，当前 Tab 为柔和的蓝色胶囊，图标与标签同步强调；每个入口保持足够触控面积及安全区适配。

桌面端保留左侧栏与右侧内容区。品牌区使用海洋标识和简洁标题，导航项以圆角容器区分当前入口；未选中项仅在交互反馈中出现轻微表面变化。

## 页面布局

首页保留余额、最近会话和会话列表的数据结构。顶部快捷信息调整为更清晰的卡片组，使余额信息和继续对话入口的层级一目了然；会话列表与顶部区块之间建立统一留白。

智能体与群聊页保留创建、进入、编辑、删除等动作。列表项改为独立的轻卡片，统一头像尺寸、标题、摘要、箭头与内边距；空状态采用同样的图标、标题、说明和主操作布局。

网络页保留现有内容与交互，只调整标题区、内容分组、卡片表面和间距以接入通用视觉令牌。

账户页保留登录、余额、订阅、同步、反馈、退出和设置行为。用户、额度和订阅信息使用区分明确的卡片分组；高风险退出操作保留错误色，但降低其余操作的视觉竞争。

## 交互与可访问性

保留所有现有点击、长按、刷新、页面跳转和加载行为。卡片和导航项使用 Material 的涟漪及圆角裁切提供按压反馈，不引入影响列表滚动性能的持续动画。

文字、图标和边框均从 `ColorScheme` 派生，确保浅色和深色模式的对比度。所有列表项保留现有可点击区域或扩展到完整卡片，按钮与图标保持语义化 Material 控件。

## 验证

执行 `flutter analyze`，要求没有 error；运行现有 `flutter test`。人工检查手机和桌面断点下的五个主 Tab，并检查浅色、深色模式中的导航、文本、卡片和空状态。

## 非目标

- 不重新设计聊天页及创建、设置、登录等非主 Tab 页面。
- 不修改服务层、provider、数据库、API、路由及本地化数据。
- 不增加第三方 UI、字体或动画依赖。
