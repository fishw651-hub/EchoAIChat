# 移动端折射液态玻璃底部导航设计

## 背景

移动端主页已有四个 Tab、一个居中的创建入口和可滑动选中胶囊，但当前材质由模糊、透明填充和描边组成，仍然更接近普通磨砂玻璃。目标参考的关键特征是厚玻璃边圈：边缘会改变背后内容的采样位置，产生可见的凸透镜折射；中间区域则保持清透。

本次仅调整移动端主页的底部悬浮导航。桌面端侧边栏、PageView 映射、创建菜单的业务回调和菜单内容均不在范围内。

## 已确认目标

- 使用 Flutter 原生 `ImageFilter.shader` 与 `BackdropFilter`，在支持 Impeller 的设备上对真实背景纹理做局部位移采样。
- 底栏不能退化为高不透明度的磨砂面板；主要视觉应来自凸透镜边缘、方向性亮暗边与内反射。
- 中心入口取消独立圆形玻璃、上浮偏移和独立阴影，只显示稍大的加号。
- 四个 Tab 和加号置于同一底栏基线；加号保留原有创建智能体和创建群聊菜单。
- 保留选中胶囊的平移交互、浅深色主题、SafeArea、减少动态效果和当前业务行为。

## 视觉与布局

### 五槽底栏

主底栏保持悬浮圆角矩形和现有外边距。内容改为五等分：Tab 0、Tab 1、加号、Tab 2、Tab 3。四个 Tab 的图标和标签仍使用现有纵向排布。

加号的视觉中心与各 Tab 图标的视觉中心对齐，而不是与整条底栏的几何中心对齐。加号图标约为 32dp，高于 Tab 的约 26dp 图标；透明触控区保持 56dp。它不绘制圆形背景、描边、独立毛玻璃或上浮变换。按压只对图标和无形状态层做短促反馈，不改变布局。

### 四层玻璃

底栏与选中胶囊各自使用以下从下到上的分层：

1. 折射层：片元着色器根据圆角矩形的有符号距离场，只在距边界约 8 至 10dp 的区域将背景采样坐标向内偏移；中心区域直接透射背景。胶囊使用同一算法和更紧凑的圆角参数。
2. 覆盖层：极低不透明度的 `ColorScheme.surface` 覆盖和轻微模糊，避免背景文字穿透后影响 Tab 可读性，但不把底栏染成灰色。
3. 锐利边层：左上侧高光、右下侧暗边和细描边表现玻璃厚度。颜色完全由当前 `ColorScheme` 派生。
4. 内反射层：两组方向相反的内阴影/内高光，增加浅层反射，不引入渐变光球或持续动画。

选中胶囊位于 Tab 前景下方且不参与命中测试。它的折射强度与顶部高光略高于主底栏，并继续随 `currentIndex` 在四个 Tab 槽位之间平移。加号槽不参与胶囊目标位置。

## 架构与兼容性

### 组件职责

`LiquidGlassBottomNavBar` 保持接收 `ColorScheme`、`currentIndex`、`tabBuilder` 与 `centerAction` 的公开接口。它负责五槽几何、胶囊动画和玻璃分层，不接管导航或创建业务。

新增内部折射玻璃组件和一个 `.frag` 着色器资源。组件在初始化时加载 `FragmentProgram`，并通过 `ImageFilter.isShaderFilterSupported` 判断能否创建 `ImageFilter.shader`。着色器需要的尺寸、圆角和折射强度均由组件在布局完成后传入。

`MobileCreateAction` 继续拥有 `OverlayPortal`、`LayerLink`、Tooltip、语义、菜单动画和两个创建回调。它的触控形状从 `CircleBorder` 改为与槽位一致的透明点击表面，确保不会重新引入可见圆形容器。

### 降级

`ImageFilter.shader` 仅在 Impeller 后端可用。若当前后端不支持，内部玻璃组件不得创建该滤镜，改用低强度的背景模糊加相同的覆盖、锐利边和内反射层。降级只影响背景折射的强度，不影响五槽布局、Tab 切换、点击、创建菜单或主题。

### 动效与可访问性

选中胶囊维持可打断的约 320ms 水平移动，并仅在移动阶段产生轻微横向拉伸。快速切换从当前插值位置前往最新目标。图标保留一次性短促的颜色过渡与缩放；标签不位移。

`MediaQuery.disableAnimationsOf(context)` 为 true 时，胶囊和图标直接进入终态。五个槽位均保留至少 48dp 的有效触控区域，创建入口保留“新建”Tooltip 和可访问语义。

## 范围

### 包含

- 移动端 `LiquidGlassBottomNavBar` 的折射滤镜、视觉层、五槽布局和胶囊几何。
- `MobileCreateAction` 的无圆形创建入口与现有菜单锚点适配。
- 片元着色器资源与 `pubspec.yaml` 声明。
- 针对布局、创建菜单、着色器降级、主题和减少动态效果的定向测试。

### 不包含

- 桌面端侧边栏和其他页面的玻璃化。
- Tab 数量、PageView 映射、创建菜单内容或业务回调。
- 新增第三方依赖、截图驱动的背景纹理、每帧截屏或持续循环动画。
- Web 专用 CSS/SVG 实现。

## 测试与验收

- 组件测试验证五个槽位、四个 Tab、中心加号和胶囊只落在 Tab 槽位。
- 测试加号没有圆形玻璃容器或上浮位移，且图标尺寸大于普通 Tab 图标。
- 创建入口测试继续验证 Overlay 菜单、创建智能体和创建群聊回调。
- 为着色器支持与不支持两种路径建立可注入的能力判断，验证降级时不抛出 `UnsupportedError`。
- 在窄屏浅色、窄屏深色和减少动态效果下检查无溢出、稳定几何与可用状态。
- 运行现有主页映射、UI 清理与创建入口回归测试；使用实际移动端/模拟器截图检查折射只集中在边缘，文字和图标不被背景干扰。

## 非功能约束

- 所有视觉颜色来自 `ColorScheme`，不新增 `Colors.white` 或 `Colors.black` 主色。
- 新代码使用 `withValues(alpha: ...)`，不使用 `withOpacity`。
- 片元滤镜与模糊均裁剪到各自圆角区域；底栏以 `RepaintBoundary` 隔离，动画不改变父布局尺寸。
- 工作区已有无关修改，实施阶段不自动提交或回滚这些修改。
