# 移动端 iOS 26 风格液态玻璃底部导航设计

## 背景

当前移动端主页使用四个 Tab 和一个居中创建按钮的悬浮底栏。现有实现只叠加了背景模糊、半透明填充和静态描边，视觉上更接近普通磨砂玻璃，缺少 iOS 26 液态玻璃可感知的厚玻璃边缘、独立选中介质和流体状态过渡。

本次重新设计仅覆盖移动端底部导航。桌面端左侧导航、页面映射、创建菜单和业务状态保持不变。

## 目标

- 主底栏呈现透明、具有厚度和方向性边缘的玻璃材质，而不是灰色半透明面板。
- 当前 Tab 背后有一块独立的液态玻璃胶囊，并在 Tab 切换时流畅移动。
- 中央创建入口改为独立玻璃圆按钮，保留原有创建智能体和创建群聊菜单。
- 浅色、深色主题均保持清晰层次、足够对比度和稳定性能。
- 不新增第三方依赖，不使用持续循环的装饰动画。

## 范围

### 包含

- `LiquidGlassBottomNavBar` 的玻璃分层、布局和选中态动画。
- `_MobileTabDestination` 的选中视觉职责调整。
- `MobileCreateAction` 的按钮材质调整。
- 对应组件测试、主页回归测试和移动端视觉验证。

### 不包含

- 桌面端侧栏样式。
- PageView 页面结构、Tab 数量或页面映射。
- 创建菜单内容、定位方式和业务回调。
- 全局主题、其他卡片或弹窗的玻璃化。
- 第三方液态玻璃库或运行时 Shader。

## 视觉结构

### 主玻璃底座

主底栏保持一整块悬浮圆角玻璃。背景内容透过底栏时被适度柔化，但不能被高不透明度填充遮成灰色实心条。

玻璃厚度由多层边缘共同表达：

- 外层使用轻量悬浮阴影，将底栏与页面内容分开。
- 顶部和左上侧使用较亮的细高光，模拟光线进入玻璃。
- 底部和右下侧使用低对比暗边，模拟厚玻璃的内部折射。
- 内侧叠加非常克制的主题色折射，不能形成明显渐变色块。

所有颜色从 `ColorScheme` 派生，不硬编码 `Colors.white`、`Colors.black` 或固定品牌色。

### 选中玻璃胶囊

选中项背后放置一块独立椭圆玻璃胶囊。它拥有比主底座更明显的边缘高光、稍强的背景模糊和轻微主题色折射，但仍然能透出底层内容。

胶囊位于 Tab 内容层下方，不拦截触控。图标和文字同时改变颜色与字重，使选中状态不只依赖胶囊或单一颜色。

### 独立创建按钮

中央创建按钮从主底栏材质中分离，形成独立圆形玻璃。按钮相对主底栏向上悬浮约 10 至 12dp，并通过独立边缘、阴影和周围留白形成清晰分层。

按钮保留 56dp 可见尺寸和至少 48dp 的触控目标。加号使用主题前景色，按钮本身不再使用实心 `primary` 填充。创建菜单的锚点、展开位置、内容和回调均不改变。

## 布局约束

- 保留四个 Tab 和 64dp 中央插槽的现有顺序。
- 主底栏保持稳定高度，选中胶囊移动不得改变 Row、Tab 或文字的布局尺寸。
- Tab 触控区域至少为 48dp，图标和标签不得因动画发生重排。
- 底栏继续使用 `SafeArea`、悬浮外边距和 `Scaffold.extendBody`。
- 智能体/群聊分段控件继续位于底栏上方，不得与上浮后的创建按钮重叠。
- 小屏手机、常规手机和横屏下均不得水平溢出。

## 交互动效

### Tab 切换

当 `currentIndex` 改变时，选中胶囊从当前位置移动到目标 Tab：

- 总时长约 320ms，采用可打断的弹簧感曲线。
- 移动阶段沿水平方向轻微拉伸，到达目标后恢复原比例。
- 快速连续点击时，从当前动画位置转向最新目标，不排队播放旧动画。
- PageView 横滑完成并更新索引时，使用同一过渡。
- 图标在切换时进行一次短促的颜色过渡和 `1.0 -> 1.06 -> 1.0` 缩放。
- 标签位置保持固定，只改变颜色和字重。

动画只由状态变化触发，不存在循环控制器或持续重绘。

### 创建按钮

按下圆形创建按钮时，高光轻微收紧并产生小幅缩放，松开后恢复。菜单仍使用现有淡入和上移动画。

### 减少动态效果

当 `MediaQuery.disableAnimationsOf(context)` 为 true 时：

- 胶囊直接切换或使用极短淡入，不执行拉伸和回弹。
- 图标不缩放。
- 导航和创建菜单仍可正常操作。

## 组件边界

### `LiquidGlassBottomNavBar`

改为有状态组件，负责：

- 主玻璃底座、选中玻璃胶囊和独立圆形玻璃容器。
- 根据可用宽度计算四个 Tab 的稳定目标位置。
- 管理一次性的选中胶囊移动和拉伸动画。
- 响应主题、索引变化和减少动态效果设置。

它继续接收 `ColorScheme`、`currentIndex`、`tabBuilder` 和 `centerAction`，不接管业务导航。

### `_MobileTabDestination`

继续负责语义、点击、图标、标签和按压反馈。它不再绘制任何选中背景，避免与底栏胶囊重复。选中态只调整前景颜色、字重和一次性图标过渡。

### `MobileCreateAction`

继续负责 Overlay 菜单控制、锚点和创建回调。其可点击圆形表面改为透明材质，让 `LiquidGlassBottomNavBar` 提供的独立玻璃圆容器成为可见背景。

## 性能与兼容性

- 使用 Flutter 原生 `BackdropFilter`、裁剪、装饰层和一次性动画，不新增依赖。
- 玻璃模糊限制在底栏、选中胶囊和圆形按钮的裁剪范围内。
- 使用 `RepaintBoundary` 隔离底栏重绘，动画只重绘底栏区域。
- 不采用运行时 Shader，避免不同 GPU、Impeller 和 Web 后端的不一致。
- 平台无法提供有效背景模糊时，边缘、高光、透明填充和阴影仍构成可用的降级外观。

## 测试与验收

### 自动化测试

- 四个 Tab 和中央按钮保持存在且顺序正确。
- `currentIndex` 改变后胶囊移动到正确目标。
- 动画中间态存在位移和水平拉伸，到位后恢复稳定尺寸。
- 快速连续切换最终落在最新索引。
- `disableAnimations` 下不执行拉伸动画。
- 中央按钮由独立圆形玻璃承载，原创建菜单和两个操作仍可用。
- 浅色、深色主题均能构建，无溢出和异常。
- 原主页页面映射、创建入口和 UI 清理回归测试继续通过。

### 视觉验收

- 在窄屏移动端分别检查浅色和深色主题。
- 主底栏能看见背景透射和方向性厚玻璃边缘，不呈灰色实心面板。
- 选中胶囊与主底座材质层次清楚，切换时移动自然且不会抖动布局。
- 中央创建按钮视觉上独立于主底栏，并且不遮挡上方分段控件。
- 小屏、常规手机和横屏下文字、图标、按钮均不重叠。
