## Phase 5：全新 Git 历史 + 推送新仓库

```bash

rm -rf .git

# 2. 初始化新仓库
git init -b main
git add .
git commit -m "Initial commit: 回响 Echo — Flutter AI Chat + Go API Server (MPL-2.0)"

# 3. 添加新 remote 并推送
git remote add origin https://github.com/fishw651-hub/EchoAIChat.git
git push -u origin main
```

3. 清除客户端/文档域名泄漏

7. `rm -rf .git` → `git init` → 首次提交 → 推送

**注意**：推送前会最后确认一次 `git status` 确保无敏感文件被跟踪。
