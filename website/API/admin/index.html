📖 智能体同步 API

以下 API 用于 Flutter 端与服务端之间的智能体云端同步。
所有接口需要 Bearer JWT 认证（Authorization: Bearer <token>）。

1. 获取云端智能体列表

GET /api/v1/user/agents
参数类型说明
无-无需查询参数，通过 JWT 识别用户
查看响应示例

  "data": [

2. 创建/更新智能体

POST /api/v1/user/agents
字段类型必填说明
iduint否留空创建，传值更新
namestring是智能体名称
genderstring否性别
descriptionstring否描述
personastring否角色设定（服务端加密存储）
opening_linestring否开场白（服务端加密存储）
avatar_colorint否头像颜色 ARGB
avatar_pathstring否头像路径
chat_backgroundstring否聊天背景图
worldviewstring否世界观设定（服务端加密存储）
is_sim_characterbool否是否为模拟角色
查看请求/响应示例 
// 请求
POST /api/v1/user/agents
Authorization: Bearer eyJhbGciOi...

{
  "name": "助手小美",
  "gender": "女",
  "description": "温柔体贴的助手",
  "persona": "你是一个温柔的女助手...",
  "opening_line": "你好呀",
  "avatar_color": 4278234345,
  "worldview": "现代都市"
}

// 响应
{
  "code": 0,
  "data": {
    "id": 1,
    "created_at": "2026-06-21T12:00:00Z",
    "updated_at": "2026-06-21T12:00:00Z"
  }
}

3. 删除智能体

DELETE /api/v1/user/agents/:id
参数位置说明
idURL 路径智能体 ID（来自列表接口返回的 id）
查看响应示例 
{
  "code": 0,
  "message": "删除成功"
}
